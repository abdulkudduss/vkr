# Tourist Events Web Application

Учебный web-проект, разработанный в рамках выпускной квалификационной работы (ВКР).

## 🧭 О проекте

Web-приложение для организации туристических мероприятий и взаимодействия туристов с индивидуальными гидами.

Платформа позволяет:
- туристам находить экскурсии и гидов;
- записываться на экскурсии;
- общаться с гидами;
- гидам публиковать и управлять своими турами;
- администратору модерировать пользователей и контент.

## 👥 Роли пользователей
- Гость
- Пользователь (турист)
- Гид
- Администратор

## ⚙️ Основной функционал
- регистрация и авторизация;
- каталог экскурсий;
- поиск экскурсий и гидов;
- портфолио гида;
- заявки на экскурсии;
- сообщения и отзывы;
- администрирование данных.

## 🛠 Стек технологий
- PHP
- MySQL
- HTML / CSS
- JavaScript
- Bootstrap
- phpMyAdmin

## 🗄 База данных
Реляционная модель, 6 основных таблиц:
`пользователи`, `гиды`, `экскурсии`, `заказы`, `отзывы`, `сообщения`.

## Как развернуть базу данных

1. Открой MySQL Workbench
2. Перейди в **Server > Data Import**
3. Выбери:
   - `Import from Self-Contained File`
   - Укажи путь к `Dump20250615.sql`
   - Ниже выбери `Create New Schema`, назови, например, `mydb`
4. Нажми **Start Import**
5. Убедись, что база `mydb` появилась и в ней есть таблицы и данные
